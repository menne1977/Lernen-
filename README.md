# LRS-Trainer – Lesen & Schreiben

Übungs-App bei Lese-Rechtschreib-Schwäche (LRS) für Kinder **und** Erwachsene.

- Tagesplan „Heute trainieren“ (ca. 15 Min.), der die wirksamsten Methoden mischt
- 8 Methoden einzeln: Laute hören, Silben, Rechtschreib-Regeln, Wortstamm, Blitzlesen, Wiederholtes Lesen, Hör-Diktat, Fehlerkartei
- Auswertung „Was hilft am besten?“ pro Person
- Komplett offline, deutsche Sprachausgabe über Android

## APK
Bei jedem Push baut GitHub Actions die App. Die neueste **LRS-Trainer.apk** liegt unter *Releases → apk-neueste*.
